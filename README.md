# Информатика для первокурсника

## Цель
Мини-справочник по основам информатики для студентов первого курса. Помогает быстро вспомнить ключевые понятия и потренироваться на примерах.

## Автор
Student BoBoBo

## Выбранная тема
Системы счисления

## Список файлов
- `README.md` — описание проекта и инструкция
- `glossary.md` — глоссарий терминов
- `examples.md` — разобранные примеры
- `sources.md` — использованные источники
- `questions.md` — вопросы для самопроверки
- `.gitignore` — правила исключения файлов

## Как пользоваться справочником
1. Прочитайте этот README, чтобы понять структуру и выбранную тему.
2. Изучите термины в `glossary.md`.
3. Разберите примеры в `examples.md` — в каждом есть исходные данные, ход решения и ответ.
4. Проверьте себя по вопросам в `questions.md`.
5. При необходимости обратитесь к источникам в `sources.md`.

Тема справочника - системы счисления: двоичная, восьмеричная, шестнадцатеричная и перевод между ними.
